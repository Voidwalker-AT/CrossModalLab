# Benchmark construction and shortcut audit

Two related designs must remain distinct. Legacy displayed data have three primary variants per family with one visual relation, one text relation and a strict-left-of query. Six development-validation families provide 18 cases. Objects are rendered 2D proxies with color/name aliases and canvas jitter; a historical name such as star may be drawn as a diamond. The original labels/images are preserved, not repaired retrospectively.

The current publication generator (copied by source reference, not executed for new model results) uses six unordered entity triples. Each crosses six role permutations, 16 premise/query/modality assignments and 16 layout/prompt/content/choice-order factors: 6 x 6 x 16 x 16 = 9,216 rows. Layout/image reuse yields 72 distinct images. Exact counts and hashes were checked from every stored row. Names map to literal circles/triangles/diamonds/squares/rings in the versioned renderer; inspect src/benchmark/factorial_development.py and publication_factorial.py for the precise alias/render code. No natural images or final-holdout data enter these figures.

Reachability classifies the query using forward/reverse directed paths; exhaustive compatible total orderings independently check truth in every world. A forward chain gives Yes, reverse gives No, and the fork permits both. Each individual modality alone can leave both truth values possible while statistically predicting some labels in the restricted generator. Concrete verified example: in the 68 selected legacy records, visual bridge-left-of-query-subject occurs in 23 rows, all labeled No. The query object is absent from that premise, so it does not logically settle the query. Textual bridge-left-of-query-object occurs in 23 rows, all labeled Yes. These are generator strata, not logical entailments. The actual role keys and label counts are in supplementary_recomputation.json#concrete_role_strata; no imagined VLM behavior is used. Train-fitted text/image-role lookups each reach validation BA 2/3 on selected legacy data.

The later factorial design removes deterministic role strata but still permits single-modality oracle-role BA ceilings of 2/3. Listed nuisance-feature ceilings are 1/3; this audits specified features only. Three families fit and three evaluate lookup baselines, all exposed development. Shared entities, renderer/grammar and unknown perceptual cues remain. Neither formal cross-modal dependence nor these finite feature checks proves a shortcut-free benchmark or actual VLM composition. Do not call 9,216 variants independent observations.
