# Preserved source excerpts and snapshots

These are byte-preserved project-owned source files and research registries, copied for source-to-claim review. Their original repository-relative paths and hashes are listed in the package manifests. Links inside a copied historical Markdown document retain their original repository context; they are not an assertion that the extracted package contains the entire repository. The newly prepared figures, tables, equations and integration instructions are self-contained at the package root.

No foreign copyrighted full paper, model weights, optimizer/RNG binary or model cache is included. Full historical checkpoint/vector revalidation needs the original repository and lawful local artifacts. The package contains checked summaries, raw behavioral predictions, original selected images and plotting/recomputation code so its paper-support outputs can be inspected independently.
